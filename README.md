## 📌 Overview

**`nwd`** (`nwd.benjelloun.dev`) is a bespoke single-page digital literary publication presenting the scholarly *Taqariz* (commendatory verses and prose endorsements) composed by Moroccan scholars and litterateurs in praise of **حلية النوادي ومهمات العوادي (*Hilyat al-Nawadi wa-Muhammat al-Awadi*)**.

Designed with classical Arabic manuscript aesthetics (`Amiri` and `Scheherazade New` web typography, traditional hemistich poetry grids, and interactive scholarly commentary cards), the application bridges traditional Maghrebi literary heritage with modern responsive web engineering.

---

## ✨ Key Features

- **Classical Two-Column Hemistich (*Sadr* / *Ajuz*) Layout**: Responsive RTL poetic layout preserving classical Arabic verse alignment across desktop and mobile viewports.
- **Scholarly Commentary & Biographical Context**: Structured presentation of the commending scholars, vocalized (*mushakkal*) verses, and lexical annotations.
- **Manuscript-Inspired Dark & Gold Palette**: Built with Tailwind CSS v4, Lucide icons, and motion transitions for distraction-free reading.
- **Zero-Runtime Overhead Static Delivery**: Compiled via Vite 6 + TypeScript into a fast static bundle deployed on GitHub Pages with custom domain routing (`nwd.benjelloun.dev`).

---

## 🛠️ Tech Stack & Development

- **Frontend Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + classical Arabic web fonts (`Amiri`, `Scheherazade New`)
- **Animations & Icons**: `motion` + `lucide-react`
- **Build Tool**: Vite 6

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Type-check and build production bundle
npm run lint
npm run build
```
